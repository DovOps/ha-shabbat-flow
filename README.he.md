# ShabbatFlow

מתכנן ביתי לשבת וליום טוב עבור Home Assistant. המערכת מתוכננת לריבוי שפות, עם עברית ואנגלית כברירת מחדל ותמיכה בתצוגה מימין לשמאל.

## המצב הנוכחי
אב־טיפוס מקומי לתצוגה מקדימה בלבד. אין חיבור ל־Home Assistant, אין שליטה במכשירים ואין חישוב אוטומטי של זמני הלכה. הנתונים בדוגמה בדיוניים.

נדרש Python בגרסה 3.11 ומעלה:

```sh
PYTHONPATH=src python3 -m shabbat_flow.server
```

פתחו את http://127.0.0.1:8765 ובחרו עברית. אפשר לבחור חדרים לשינה וסעודות בבית, לשנות בנפרד את זמני החימום/קירור והתאורה, ולהציג את לוח הזמנים. אפשר לשמור, לטעון ולמחוק טיוטה בדפדפן בלבד. הייצוא כולל את ההגדרות שהוזנו; אין להוסיף למאגר פרטים של בית אמיתי. לעצירת השרת לחצו Ctrl+C.

## מגבלות
התצוגה מיועדת לשישי–שבת יחידים ולזמנים מוזנים מראש. מצבי חימום וקירור וטמפרטורות, פרופילי שינה מוקדמים ומאוחרים, שימוש בחדרים לפנאי, קבוצות מכשירים מותאמות, חגים רצופים והפעלה בפועל יפותחו בהמשך. אין להסתמך על הדוגמה כתוכנית מלאה להפעלת הבית.

## תורמים
יש להשתמש בשמות חדרים ובנתונים כלליים ובדיוניים. אין להוסיף הגדרות ביתיות אמיתיות, פרטי משפחה, סיסמאות או היסטוריית פעילות למאגר. כל מתקין יתאים את ההגדרות לביתו באופן פרטי. כל טקסט בממשק צריך להיכלל בקטלוגי התרגום.
