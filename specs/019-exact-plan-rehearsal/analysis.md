# Analysis
A rehearsal references the real plan's immutable schedule and a selected plan instant; it must not rewrite candle lighting to today's date or arm a future run. Reuse existing binary dispatch and source/registry checks, but isolate storage, lifecycle and restoration from normal execution. Provider status gates real tests while simulation remains available. Shared-area demand remains global when projecting state, so a selected bedroom cannot turn a shared light off contrary to another selected use. Selection then filters physical targets, never recomputes a different household plan.
