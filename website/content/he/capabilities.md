# מה אפשר לעשות היום

| יכולת | היקף נוכחי |
| --- | --- |
| אשף חדרים | זיהוי אזורים, התקנים וישויות HA; סינון תוויות; תפקידים וחדרי רחצה משותפים |
| לוח שנה | אירועים עתידיים מ־Jewish Calendar; חלופה ידנית; תקופות רצופות מרובות ימים |
| תצוגת תוכנית | תאורה ומיזוג בנפרד, ארוחות, שינה, מנוחה ומעברי לילה ובוקר |
| דוחות חזותיים | רשימת אירועים, צירי תאורה ומיזוג, JSON ו־PDF / הדפסה |
| תצפית | השוואת תוכנית ומחקרי אקלים עצמאיים של 1–48 שעות; פערים מוצגים במפורש |
| הודעות | ערוצי SMS ודחיפה אופציונליים ותזכורות לפני נרות; נדרשת הפעלה מפורשת |
| הפעלת התקנים | **ניסוי תאורה לבחירה לאחר אימות, אישור ותזמון נפרדים. מיזוג, מאווררים ומכשירי חשמל מוחרגים.** |
| אימות רשמי של HA | **טרם אושר. שילוב עצמאי מותאם.** |

## תלויות ברורות

רכיבי הממשק, HTTP והלוח המותאם של HA מארחים את השילוב. אזורים נדרשים להגדרת חדרים וישויות אקלים זמינות נדרשות למחקר. Jewish Calendar מועדף לתאריכים אוטומטיים עם חלופה ידנית. מזג אוויר, חיישני השוואה, תוויות, קריאת אוטומציות, Twilio ודחיפה הם אופציונליים. ההגדרות מציגות זיהוי, חוסר או צורך בהגדרה והנחיות פעולה.

זיהוי אינו הוכחת מסירה לטלפון, כיסוי מלא של חג או תחזית מלאה לכל אוטומציה. יש לאמת מסירה וייצוא PDF בנייד בהתקנה המסוימת.

## הדרך להפעלה עתידית

מפרט הביצוע כולל הפעלה מפורשת, בעלות על התקנים, התנגשויות עם אוטומציות קיימות, הפעלה וכיבוי מיזוג תוך שימור הגדרות והתאוששות מהפעלה מחדש. תת־קבוצה לתאורה יושמה עם בדיקות בעלות שמרניות ותיקון מוגבל לבחירה. מתאמי מיזוג ומאווררים, העברות שליטה ואימות חי עדיין פתוחים. תוכנית שמורה אינה פועלת אוטומטית: נדרשים בדיקה, אישור ותזמון מפורשים.

[מפת הדרכים](reference/docs/roadmap.md) ו[מצב הדרישות](reference/docs/requirements-status.md) נשמרים באנגלית במאגר כמקור מוסמך.
