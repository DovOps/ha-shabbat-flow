# פיתוח מתוך הדרישות

ShabbatFlow מפותח בתהליך מבוסס מפרטים: דרישות, תוכנית יישום, משימות, ניתוח, מימוש ואימות. עדכנו דרישות פונקציונליות ולא־פונקציונליות יחד עם שינויי הקוד.

המאגר הציבורי מכיל דוגמאות כלליות בלבד. יש לשמור פרטי משפחה, מזהי התקנים אמיתיים, היסטוריית בית, סודות וצילומי התקנה פרטיים מחוץ למאגר. השתמשו בנתוני בדיקה בדיוניים ובמיתוג המקורי. אין לטעון לחסות HA או להעתיק עיצובים של שילובים אחרים ללא סקירה.

קראו את [הוראות התורמים](https://github.com/DovOps/ha-shabbat-flow/blob/main/AGENTS.md), [חוקת הפרויקט](https://github.com/DovOps/ha-shabbat-flow/blob/main/.specify/memory/constitution.md) ו[החלטות התלויות](reference/docs/dependencies.md). יש לחתום על תרומות באמצעות DCO עם `git commit -s`.

## שמירת האתר מעודכן

תוכן ההסבר והמדריכים נמצא ב־`website/src` וב־`website/content`. המקורות הטכניים נוצרים אוטומטית מ־`specs/` וממסמכים נבחרים תחת `docs/`. יש לערוך את המקורות, לא את הפלט שנוצר. גרסת השילוב נקראת ישירות מקובץ ה־manifest.

מתיקיית המאגר:

```sh
cd website
npm ci
npm run build
npm run check
npm run serve
```

התצוגה המקומית נמצאת ב־`http://localhost:3000/ha-shabbat-flow/`; עברית ב־`/ha-shabbat-flow/he/`. לפיתוח באנגלית עם רענון חי השתמשו ב־`npm start`, ולעברית ב־`npm start -- --locale he`. לאחר שינוי מפרטים מקוריים יש להריץ שוב הכנת תוכן.

בקשות מיזוג בונות את שתי השפות. לאחר הפעלת Pages, עדכונים ל־`main` מפרסמים את האתר דרך GitHub Actions. מדריך תחזוקת האתר במאגר מפרט את ההגדרה הראשונית.
