# Branding

Product: ShabbatFlow. Repository convention: ha-shabbat-flow.

The current original mark uses two candles and a flowing ribbon. It does not use the Home Assistant house or antenna. Cyan target: `#18BCF2`, as published in Home Assistant's primary-50 color tokens: https://github.com/home-assistant/frontend/blob/dev/src/resources/theme/color/core.globals.ts . Warm flame colors and navy text distinguish the composition. Raster generation may not reproduce every color pixel exactly; production vector cleanup can follow final brand approval.

Generated with the built-in image-generation tool. The image-edit prompt and original design prompt are in assets/logo-prompt.txt. A discarded derivative concept based on the official Home Assistant mark is not included in this repository. Do not claim endorsement or trademark clearance. Reference guidance: https://contributors.home-assistant.io/brand/name-and-logo/ .

The local preview header serves this exact approved asset at `/logo.png`, with responsive sizing and a ShabbatFlow accessible name. No third-party logo or remote image fetch is used.

Approved dashboard tagline: “A peaceful Shabbat starts with a plan.” Hebrew: “שבת שלווה מתחילה בתכנון.” The existing logo image remains unchanged; its embedded earlier tagline has not been regenerated.
